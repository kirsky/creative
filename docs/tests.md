# Тесты и контроль качества

**2325 автоматических тестов** в трёх слоях плюс статические проверки. Всё запускается одной командой `make check` (без E2E) и в GitHub Actions на каждый push.

| Слой | Инструмент | Тестов |
|---|---|---|
| Backend | PHPUnit, интеграционные на MariaDB без моков БД (отдельная тестовая БД) | **1433** (14 029 проверок) |
| Frontend | Jest + React Testing Library | **878** в 57 наборах |
| E2E | Playwright (Chromium, RU и EN) | **14** |

## Backend: 1433 теста

| Набор | Тестов | Что проверяется |
|---|---|---|
| Tasks | 801 | Автомат статусов: каждый допустимый и недопустимый переход; матрица «роль × действие»; видимость задач; атомарное взятие при одновременных запросах; правка брифа с аудитом |
| Files | 142 | Загрузка, проверка типа по содержимому, лимиты, скачивание только с правом на задачу |
| Shared | 119 | Валидация, формат ошибок, доверенные прокси, обработка некорректного ввода |
| Identity | 114 | Вход, сессии, CSRF, лимит попыток, ротация паролей, доступ по умолчанию закрыт |
| Rounds | 88 | Сдача раундов, приёмка, правки, отмена, возврат в пул |
| AiUsage | 73 | AI-расходы по раундам, агрегация по сервисам и исполнителям, гонка при создании сервиса |
| Demo | 30 | Демо-данные создаются через реальные сервисы приложения |
| Metrics | 27 | Расчёт времени из событий, включая возврат в пул и повторное взятие |
| History | 25 | Журнал событий и аудит полей только на добавление |
| Analytics | 13 | Данные дашборда и фильтр по периоду |
| Api | 1 | Каждый маршрут совпадает с [OpenAPI-контрактом](../backend/openapi/openapi.yaml) в обе стороны |

Большинство наборов параметризованы, поэтому число запусков больше числа методов.

## Frontend: 878 тестов

Формы и валидация (коды ошибок превращаются в переводы), диалоги действий, доска (перетаскивание и управление с клавиатуры, фильтры), страница задачи, «Моя работа», дашборд и графики, переключение языка, русские формы множественного числа. Отдельные скрипты проверяют совпадение ключей перевода в `en` и `ru` и настройки сборки.

## E2E: 14 тестов

- **Пятиминутный сценарий** (`story`), отдельно на английском и русском: байер, креативщик и руководитель проходят весь цикл задачи.
- **Права** (`permissions`, 6): вход без сессии, общее сообщение при неверном пароле, 401 на каждый API-вызов без сессии, запрет дашборда креативщику и чужой задачи байеру, повторный вход после выхода.
- **Экраны** (`screens`, 6): каждая роль в светлой (EN) и тёмной (RU) теме, на 1280 и 390 px, без горизонтальной прокрутки.

## Статические проверки

PHPStan level 10, PHP CS Fixer (PER), ESLint, Prettier, Stylelint, `tsc --checkJs` (типы JSDoc), `nginx -t`, `docker compose config`, совпадение ключей перевода.

## Запуск

```sh
make check                                  # всё, кроме E2E
make php-test ARGS="--testsuite Identity"   # один набор PHPUnit
make js-test ARGS="board"                   # Jest по имени
make e2e CONFIRM=yes                        # разрушающая: сбрасывает данные и меняет пароли
```
